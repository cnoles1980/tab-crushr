# Privacy Policy for Tab Crushr

Effective date: June 30, 2026

Tab Crushr is a Chrome extension that helps users review, save, close, and discard duplicate, related, stale, and superseded browser tabs.

## Data Collected

Tab Crushr stores the following data locally in the user's browser:

- Open tab URLs
- Tab titles
- Tab navigation and reload timestamps
- Tab cleanup candidates
- Saved-for-later URLs
- Cleanup history
- Lifetime tabs crushed
- Estimated memory saved
- Achievement progress
- Extension settings

## How Data Is Used

This data is used only to provide Tab Crushr's core features:

- Detecting duplicate tabs
- Detecting related tabs from the same site
- Detecting stale tabs after 72 hours of local tracking
- Detecting superseded tabs
- Saving selected URLs for later
- Showing cleanup history
- Showing lifetime stats and achievements
- Remembering extension settings

## Data Sharing

Tab Crushr does not sell, transfer, or share user data with third parties.

## Remote Servers

Tab Crushr does not send user data to remote servers. All data is stored locally in the user's Chrome browser using Chrome extension storage.

## Remote Code

Tab Crushr does not load or execute remote code. All JavaScript, HTML, CSS, and image assets are packaged with the extension.

## Incognito

Incognito scanning is disabled by default. If the user enables incognito access in Chrome and turns on the Incognito toggle in Tab Crushr, incognito tab metadata is used only for the current browser session where supported.

## Limited Use

Tab Crushr's use and transfer of information received from Chrome extension APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
